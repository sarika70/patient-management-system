# 🏥 Patient Management System

## 📌 Project Description

The Patient Management System is a software application designed to manage patient records efficiently. It helps in storing, updating, and retrieving patient information in a structured and organized way.

## 🚀 Features

* Add new patient records
* Update patient details
* Delete patient records
* View patient information
* Database integration
* User-friendly interface

## 🛠️ Tech Stack

* Language: Python
* Database: SQL / SQLite
* Tools: VS Code, Git, GitHub

## 📂 Project Structure

```
patient-management-system/
│── main.py
│── database.db
│── requirements.txt
│── README.md
```

## ⚙️ How to Run the Project

1. Clone the repository:

```
git clone https://github.com/sarika70/patient-management-system.git
```

2. Navigate to project folder:

```
cd patient-management-system
```

3. Run the program:

```
python main.py
```
